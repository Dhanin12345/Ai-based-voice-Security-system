## 1. System Overview

VoiceGuard AI combines high-fidelity digital signal processing (DSP) with machine learning to identify synthetic acoustic artifacts generated by modern neural text-to-speech (TTS), voice conversion models, and deepfake vocoders (e.g., ElevenLabs, Tortoise, Bark, VITS).

The platform safeguards communication channels by:
1. Streaming raw 16-bit 16kHz PCM audio from web browsers over full-duplex WebSockets.
2. Inspecting uploaded forensic audio records (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`).
3. Extracting 44-dimensional acoustic vectors across temporal sliding windows.
4. Classifying voices with a 65% human-confidence threshold (`HUMAN VOICE` vs `ROBOTIC VOICE / AI VOICE`).
5. Fingerprinting unknown caller embeddings to track repeat callers and automatically enforce security blocks upon 3 repeated suspicious attempts.

---

## 2. Key Features

- **🎙️ Real-Time Microphone Stream Detection**: Sub-second temporal sliding window analysis via WebSockets.
- **🔍 44-Dimensional Acoustic Feature Extraction**: Evaluates MFCCs, Spectral Centroid, Bandwidth, Rolloff, Flatness, Zero Crossing Rate (ZCR), RMS Energy, and Fundamental Frequency (Pitch F0).
- **📞 Unknown Caller Repeated Voice Protection**: Autonomous acoustic embedding comparison that intercepts and blocks persistent fraud callers after 3 attempts.
- **💬 Scam Dialogue & Intent Analysis**: Integrated NLP intent evaluator that scores conversational coercion, urgency, and OTP/banking phishing cues.
- **🔔 Live Telemetry & HUD Notification Feed**: Real-time event notifications displaying exact data update dates and incident timestamps.
- **📄 Forensic Audit Reports**: Downloadable evaluation certificates with complete acoustic breakdowns in JSON and CSV formats.
- **⚙️ Configurable Risk Engine**: Sensitivity tuning with dynamic risk thresholds (`LOW`, `MODERATE`, `HIGH`, `CRITICAL`).

## 6. Installation & Quick Start

### Prerequisites
- **Python**: Version 3.10, 3.11, or 3.12
- **Git**
- **Microphone** (for live audio testing)

### Step 1: Clone the Repository
```bash
git clone https://github.com/Dhanin12345/Ai-based-voice-Security-system.git
cd Ai-based-voice-Security-system
```

### Step 2: Set Up Virtual Environment

**On Windows:**
```powershell
python -m venv venv
.\venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

**On Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Step 3: Run the Application
```powershell
# Using the master pipeline runner:
python run_pipeline.py --server

# Or directly with Uvicorn:
uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

## 8. Dataset & Automated ML Data Pipeline

VoiceGuard AI includes an end-to-end data pipeline to train and update models.

### One-Command Full Pipeline Update
To generate fresh audio, extract acoustic features, and retrain the classifier in a single command:
```powershell
python ml/update_data.py --samples 30 --clean
```

### Check Current Data & Model Status
```powershell
python run_pipeline.py --status
```

### Step-by-Step Training Workflow
1. **Generate Raw Samples**:
   ```powershell
   python ml/generate_dataset.py --samples 30 --duration 3.0 --clean
   ```
2. **Extract Features**:
   ```powershell
   python ml/build_dataset.py --dataset dataset --output dataset/features.csv
   ```
3. **Train Classifier**:
   ```powershell
   python ml/train_model.py --dataset dataset --model rf
   ```

## 9. REST & WebSocket API Documentation

FastAPI serves an interactive OpenAPI interface at `http://127.0.0.1:8000/docs`.

### Primary Endpoints:

#### 1. Real-Time Streaming (WebSocket)
- **URL**: `WS /ws/detect`
- **Payload**: Binary 16-bit PCM chunks (16,000 Hz, mono)
- **Response**: Live detection JSON with human confidence, synthetic probability, and risk score.

#### 2. File Inspection (REST)
- **Method**: `POST /api/detect/upload`
- **Body**: Multipart form data with audio file (`.wav`, `.mp3`, `.m4a`)
- **Response**: Forensic evaluation payload with complete 44-D acoustic vectors and mitigation actions.

#### 3. Forensic Reports
- **Method**: `GET /api/reports/{id}?format=json` (or `?format=csv`)
- **Response**: Comprehensive audit record for compliance and legal documentation.

#### 4. Repeated Caller Simulation
- **Method**: `POST /api/caller-protection/simulate-call`
- **Parameters**: `repeat_count=1`, `repeat_count=2`, or `repeat_count=3`
- **Response**: Caller profile status, embedding similarity score, and block decision.

## 10. Repeated Caller Protection Engine

The repeated caller engine protects against persistent social-engineering attackers trying multiple voice variations:

```
[ Call 1 ] ➔ Repeat Count: 1/3 ➔ State: MONITORING ➔ Alert: Normal / Suspicious Check
[ Call 2 ] ➔ Repeat Count: 2/3 ➔ State: SUSPICIOUS ➔ Alert: High Priority Warning
[ Call 3 ] ➔ Repeat Count: 3/3 ➔ State: BLOCKED    ➔ Action: AUTO-BLOCK CALLER TERMINATION
```

- **Reset Data**: Click **"Reset Test Data"** in `/caller_protection.html` or call `POST /api/caller-protection/reset-demo` to return the caller to clean monitoring state.
- **Unblock Caller**: Click **"Unblock Caller"** or call `POST /api/caller-protection/unblock` to reset repeat counters and unlock profile.

## 11. Database Schema

Managed through SQLAlchemy in `backend/models/database.py`:

| Column | Type | Description |
| :--- | :--- | :--- |

## 13. Privacy & Security

1. **In-Memory Streaming**: Live microphone streams are processed exclusively in RAM buffers and never stored to disk.
2. **Auto-Cleanup**: Uploaded inspection files are removed immediately after feature extraction.
3. **Privacy-Conscious Logging**: Audit logs preserve acoustic metrics and risk levels without capturing raw conversational content.

---

## 14. Disclaimer

VoiceGuard AI utilizes probabilistic machine-learning models to detect acoustic synthesis markers. While engineered to maximize precision, acoustic variance and compression in cellular telephony may affect scores. Detection results should be used as decision-support telemetry alongside multi-factor identity verification.
